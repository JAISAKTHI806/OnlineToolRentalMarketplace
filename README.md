# Borrowed — Online Tool Rental Marketplace

A responsive, animated marketplace demo for renting tools from nearby hosts across Tamil Nadu. The site is built with plain HTML, CSS, and JavaScript, so it runs directly in a browser without a database or build step.

## Run it

Open `index.html` in a modern browser. For the best experience, use a small local web server or the Live Server extension in VS Code.

## Demo features

- Search by tool name, category, neighborhood, and pickup/return dates.
- Browse 45 sample listings including 22 power tools, plus hammers, screwdriver sets, spanners, pliers, garden tools, ladders, and more. Prices are shown in Indian rupees (₹).
- Find listings in Coimbatore, Chennai, Salem, Kumbakonam, Trichy, Thanjavur, Erode, Namakkal, Madurai, Theni, Tiruppur, Dindigul, Vellore, Karur, and nearby towns.
- View custom, illustrated 3D-style SVG artwork for the different tool types. Uploaded photos appear on their listings instead.
- Reserve one or more tools, enter renter details, and complete a simulated checkout.
- Review bookings under **My rentals**. Statuses show as Reserved, Rented, Returned, or Overdue based on dates and host updates.
- See nearby or same-category suggestions when a search has no available results.
- Use **Host desk** to add listings, upload a tool photo with an automatic preview, mark tools for maintenance, and update rental statuses.
- Tool listings, favorites, and rental records persist in the browser's local storage.
- Gabriola typography with a 14 px base size, richer workshop-inspired colors, animated floating tool illustrations, 3D hover effects, and responsive layouts; respects reduced-motion preferences.

## Demo notes

This is a front-end project prototype. Checkout is simulated: no payment is collected or stored. Listings, uploaded photos, favorites, and rental data are stored only in the current browser profile, so they are not shared between devices or users. Authentication, a real payment provider, and a server/database would be needed for a production marketplace.
