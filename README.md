# OnlineToolRentalMarketplace — Borrowed

A responsive, animated marketplace demo for renting tools from nearby hosts across Tamil Nadu. It is built with plain HTML, CSS, and JavaScript, so it runs directly in a browser without a database or build step.

## Run it

Open `index.html` in a modern browser. For the best experience, use a local web server or the Live Server extension in VS Code.

## Demo features

- Search by tool name, category, neighborhood, and pickup/return dates.
- Browse 45 sample listings, including 22 power tools, hand tools, garden tools, workshop equipment, ladders, and more. Prices are shown in Indian rupees (₹).
- Find listings in Coimbatore, Chennai, Salem, Kumbakonam, Trichy, Thanjavur, Erode, Namakkal, Madurai, Theni, Tiruppur, Dindigul, Vellore, Karur, and nearby towns.
- View custom 3D-style SVG illustrations; uploaded photos appear on their listings.
- Reserve tools, enter renter details, and complete a simulated checkout.
- Review bookings in **My rentals**. Rental statuses include Reserved, Rented, Returned, and Overdue.
- See nearby or same-category suggestions when a search has no available results.
- Use **Host desk** to add listings, upload tool photos, manage maintenance, and update rental statuses.
- Tool listings, favorites, and rental records persist in the browser's local storage.
- Includes animated tool illustrations, hover effects, responsive layouts, Bodoni MT body text, Gabriola headings, and reduced-motion support.

## Demo notes

This is a front-end prototype. Checkout is simulated: no payment is collected or stored. Listings, uploaded photos, favorites, and rental data are stored only in the current browser profile, so they are not shared between devices or users. Authentication, a real payment provider, and a server/database would be needed for a production marketplace.
